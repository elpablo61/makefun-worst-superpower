Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe)
bounty on [make.fun](https://make.fun): invent the most useless superpower in one
line of at most 140 characters.

## The line

> I can count every grain of rice in a bowl, perfectly, but only after you've
> finished eating it. Last night: 6,214.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
